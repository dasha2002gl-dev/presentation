Task 1: There is / are & some/any/a lot of

Complete with: is, are, some, any, a, an
1. There ___ a big park near my house. is
2. There aren't ___ supermarkets in this village. any
3. There ___ ___ lovely flowers in the garden. are some
4. Is there ___ bus station? a
5. There are ___ lot of tourists every summer. a
Correct the mistakes
✏️ "There are a lot of some shops." → There are a lot of shops.
✏️ "There isn’t a some hospital." → There isn’t a hospital.
✏️ "There are any nice cafes?" → Are there any nice cafes?

Need + noun / need + infinitive

Write the correct form
🌵 In the desert, you ________ (water) every day.need water (noun)

📱 She ________ (charge) her phone before the trip.needs to charge
🎒 I ________ (a backpack) for the hike.need a backpack

Error correction & word order

❌ “There are any good restaurants nearby.” → There are some good restaurants nearby.
❌ “We need to watch the map carefully.” → We need to look at the map carefully.
❌ “She doesn’t need some help.” → She doesn’t need any help.
Put the words in order
(there / a lot of / are / parks)There are a lot of parks.
(need / you / to drink / water)You need to drink water.
